# Shared Assets

Cross-channel reusable assets live here (or in the legacy shared folders):

- `sfx/`: shared sound effects (legacy location: `music_library/sfx/`, staged to `remotion-composer/public/sfx/`)
- `textures/`: shared 35mm film grain & archival overlays (canonical copy: `remotion-composer/public/textures/`)

Channel-specific bumpers, characters, BGM, and textures live under `channels/<channel-id>/assets/`.
